# SPECIAL™ — Luxury Online Clothing & Essentials Brand

An ultra-modern, editorial, fully-responsive e-commerce website built with pure **HTML5**, **CSS3**, and clean vanilla **JavaScript**.

---

## 🌟 Brand Overview
**SPECIAL** is an independent luxury streetwear and contemporary essentials apparel brand. The design follows minimalist, high-end aesthetics inspired by luxury labels (Fear of God, Acne Studios, Represent, Zara Origins), featuring:
- Monochrome palette with warm champagne gold accents
- Architectural typography (`Syne`, `Plus Jakarta Sans`, and `Playfair Display`)
- Subtle micro-interactions, smooth hover transitions, and sticky glassmorphism headers

---

## 🛍️ Features & Functionalities

### 1. **Complete E-Commerce Architecture**
- **`index.html`**: Signature editorial homepage featuring a full-bleed luxury banner, value propositions, category division showcase, bestseller product grid, brand philosophy lookbook, verified customer reviews, and VIP newsletter signup.
- **`shop.html`**: Full catalog with live category filtering (All, Men, Women, Unisex), dynamic price range slider ($40 - $300), multiple sorting criteria (Price Low/High, Newest, Rating), and reset filters button.
- **`product.html`**: Comprehensive Product Detail Page (PDP) with high-resolution image gallery thumbnails, color swatch selection, size matrix buttons, quantity counter, "Add to Bag", and "Complete The Look" cross-sell grid.
- **`cart.html`**: Dedicated shopping bag with real-time tax calculation, free VIP shipping threshold meter ($100), working promo code simulator (`SPECIAL20` for 20% off), and checkout order simulator.
- **`about.html`**: Atelier heritage story, sustainable organic materials philosophy, and detailed international garment sizing matrix.
- **`contact.html`**: VIP concierge inquiry form, boutique flagship addresses (New York SoHo, London Mayfair, Tokyo Ginza), and interactive FAQ accordion.

### 2. **Interactive UI Components**
- **Slide-in Cart Drawer**: Accessible from any page via the bag icon or "Quick Add" buttons. Displays interactive quantity increments, deletes, subtotal, and dynamic free shipping progress bar.
- **Persistent Cart & Wishlist**: Powered by `localStorage` — items remain in the cart across page reloads and between pages.
- **Product Quick View Modal**: Preview and choose color/size options directly from product listing cards without reloading.
- **Live Search Modal**: Real-time keyword filter across products by name, division, or description.
- **Floating Toast System**: Elegant notifications for item additions, removals, wishlist updates, and promo codes.
- **100% Responsive Design**: Tailored layouts for Mobile, Tablet, Laptop, and Desktop screens.

## 🚀 How to Run the Website
Simply double-click **`index.html`** in your browser, or run a local server:

```powershell
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve
```
Then visit `http://localhost:8000` in your web browser.
